# S-wind Algebraic Priority Discoveries

## Core Principle: Algebra First, Numbers Last

S-wind now operates on the principle of **algebraic priority**:
1. Build symbolic algebraic expressions first
2. Perform numerical verification only at the end
3. Results retain complete algebraic structure

## New Internal Module: `symbolic::algebraic`

A new module was added to S-wind's core (`src/symbolic/algebraic.rs`) that provides:

- `AlgebraicBase`: Atomic units (Rational, √n, φ, π, e, ln(n), γ, α, α⁻¹)
- `AlgebraicTerm`: coefficient × base^power
- `AlgebraicExpr`: Sum of algebraic terms with:
  - `to_f64()`: Numerical approximation (for verification)
  - `try_eval_exact()`: Pure rational evaluation when possible
  - `to_latex()`: Symbolic LaTeX output
  - `complexity()`: Measure of algebraic simplicity
